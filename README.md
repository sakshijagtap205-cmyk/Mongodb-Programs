# MongoDB Practical Programs

This repository contains a collection of MongoDB practical programs designed to demonstrate fundamental and important MongoDB database operations.

## Topics Covered

- Database and Collection Creation
- Insert One and Insert Many
- Find and Retrieve Documents
- Update Documents
- Delete Documents
- Sorting and Filtering
- Comparison Operators
- Aggregation Framework
- Indexing
- Limiting Records

## Technologies Used

- MongoDB
- MongoDB Shell (mongosh)
- NoSQL Database

## Learning Objectives

- Understand MongoDB database concepts.
- Perform CRUD operations.
- Work with MongoDB query operators.
- Retrieve and manipulate documents.
- Perform data aggregation.
- Understand indexing and query performance.

## How to Run

1. Install MongoDB Community Server and MongoDB Shell.
2. Open the terminal.
3. Start MongoDB.
4. Run `mongosh`.
5. Execute the JavaScript program files.
